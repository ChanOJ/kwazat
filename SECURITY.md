# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, never in a public issue:

- **Preferred**: GitHub > this repository > **Security** > **Report a vulnerability**
  (private vulnerability reporting);
- or by email: `abuse@kwazat.fyi` (also listed in
  [security.txt](https://www.kwazat.fyi/.well-known/security.txt)).

Include what is affected (site, API, researcher, infrastructure), how to reproduce it and the
impact you see. Please allow a reasonable time for a fix before any disclosure.

## Scope

- `www.kwazat.fyi`, `kwazat.fyi`, `kwazat.com` and `test.kwazat.fyi`;
- the code and the infrastructure description in this repository.

Out of scope: denial of service, social engineering, and reports from automated scanners
without a demonstrated impact.
